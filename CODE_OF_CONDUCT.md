# Code of Conduct

This document uses ASD-STE100 Simplified Technical English.

## Our Standard

This project welcomes contributors of all backgrounds.
Keep all interactions in issues, pull requests, discussions, and reviews respectful, professional, and constructive.

Unacceptable behavior includes harassment, personal attacks, discrimination, intimidation, and deliberate disruption of collaboration.

## Enforcement

Maintainers may remove comments, close discussions, reject contributions, or block participation when behavior violates this code.

## Reporting

Report conduct concerns privately to the maintainer through https://omkhar.net.

If you cannot use a private channel, open a minimal public issue. Request a private follow-up.

When you report, include links/screenshots and a short timeline so maintainers can act quickly.

## Scope

This code applies to all repository spaces and project-managed communication channels.
